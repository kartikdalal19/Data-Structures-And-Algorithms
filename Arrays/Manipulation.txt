* What is Array Manipulation?

Array manipulation means performing operations like:

Access

Update

Insert

Delete

Search

Sort

Reverse

Rotate

Merge

Split

Traverse

Transform





1️)  Array Creation & Initialization
int[] arr = new int[5];              // Declaration
int[] arr2 = {10, 20, 30, 40};       // Initialization




2️) Traversing an Array
Using for
for(int i = 0; i < arr.length; i++)
    System.out.print(arr[i] + " ");



Using enhanced for
for(int x : arr)
    System.out.print(x + " ");






3️) Accessing & Updating Elements
int value = arr[2];   // Access
arr[2] = 100;         // Update






4️) Insertion in Array (Index-based)
Insert element at a position (shift right)
int pos = 2, element = 50;

for(int i = n-1; i > pos; i--)
    arr[i] = arr[i-1];

arr[pos] = element;


-  Arrays are fixed-size, so insertion assumes extra space.







5️) Deletion from Array
Delete element at index
int pos = 2;

for(int i = pos; i < n-1; i++)
    arr[i] = arr[i+1];

n--; // logical size reduced







6️) Searching in Array
Linear Search
for(int i = 0; i < n; i++)
    if(arr[i] == key)
        return i;

Binary Search (sorted array)
Arrays.sort(arr);
int index = Arrays.binarySearch(arr, key);







7️) Sorting Array
Arrays.sort(arr);   // Ascending

Descending
Integer[] a = {5,2,9};
Arrays.sort(a, Collections.reverseOrder());







8️) Reversing an Array
int l = 0, r = arr.length - 1;

while(l < r){
    int temp = arr[l];
    arr[l] = arr[r];
    arr[r] = temp;
    l++;
    r--;
}







9️) Rotation of Array
Left Rotation by 1
int first = arr[0];
for(int i = 0; i < n-1; i++)
    arr[i] = arr[i+1];
arr[n-1] = first;

Right Rotation by 1
int last = arr[n-1];
for(int i = n-1; i > 0; i--)
    arr[i] = arr[i-1];
arr[0] = last;







10) Merging Two Arrays
int[] c = new int[a.length + b.length];
int k = 0;

for(int x : a) c[k++] = x;
for(int x : b) c[k++] = x;







11) Splitting an Array
int mid = arr.length / 2;
int[] left = Arrays.copyOfRange(arr, 0, mid);
int[] right = Arrays.copyOfRange(arr, mid, arr.length);







1️2) Finding Max / Min
int max = arr[0], min = arr[0];

for(int i = 1; i < arr.length; i++){
    if(arr[i] > max) max = arr[i];
    if(arr[i] < min) min = arr[i];
}







1️3) Sum / Average of Array
int sum = 0;
for(int x : arr) sum += x;

double avg = (double) sum / arr.length;







1️4) Count Frequency of Elements
HashMap<Integer, Integer> map = new HashMap<>();

for(int x : arr)
    map.put(x, map.getOrDefault(x, 0) + 1);







1️5) Remove Duplicates (Sorted Array)
int j = 0;
for(int i = 1; i < n; i++)
    if(arr[i] != arr[j])
        arr[++j] = arr[i];

int newSize = j + 1;







16) Compare Two Arrays
boolean same = Arrays.equals(arr1, arr2);







1️7️) Copy Array
int[] copy = Arrays.copyOf(arr, arr.length);







1️8️) 2D Array Manipulation
Traversal
for(int i = 0; i < r; i++)
    for(int j = 0; j < c; j++)
        System.out.print(mat[i][j] + " ");







Row-wise Sum
for(int i = 0; i < r; i++){
    int sum = 0;
    for(int j = 0; j < c; j++)
        sum += mat[i][j];
    System.out.println(sum);
}
